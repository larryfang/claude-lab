# Bug audit — 2 October 2026

The account and course review fixed **28 confirmed issues**, including the reported lesson flashing and scroll reset. Google/Gmail remains the recommended sign-in option; GitHub is supported and email/password forms are removed. The audit used the local preview at http://127.0.0.1:4173/#/account. Publication is checked separately during release.

The audit covered account lifecycle and privacy, progress storage/import/reset, learning widgets, search, lesson recovery, simulations, keyboard access, mobile layouts, and the anonymous collector. Parallel reviewers could not start because the workspace had no remaining agent credits; findings were investigated and reproduced directly instead. Every fix is covered by a regression check. Related symptoms with one cause are grouped together below.

## Confirmed findings and fixes

| # | Confirmed behavior | Result after the fix | Regression evidence |
|---|---|---|---|
| 1 | Background sync treated reordered JSON fields as changed progress, repeatedly rerendering a lesson and resetting scroll. | Sync compares state values; an unchanged save retains the lesson DOM and scroll. | Account browser test: background sync preserves lesson content and scrolling when server reorders fields. Also checked in the live authenticated preview. |
| 2 | A malformed backup replaced good progress before rendering failed. | Validate the complete state before replacing or saving it. | Malformed-file browser regression preserves the existing completion. |
| 3 | Backup files accepted prototype-related object keys. | Reject those keys recursively before replacing a workspace. | Prototype-key import regression; existing state-path unit test. |
| 4 | Version 1 completions migrated into the removed `pm` track. | Migrate valid legacy data into Cowork. | Legacy welcome completion regression. |
| 5 | Reset progress also erased the notebook, name, and preferences. | Clear learning progress while keeping notebook entries, the local name, theme, focus preference, and planner preferences. | Reset regression checks both preserved data and cleared completions. Existing focus test now verifies the retained preference and explicit exit action. |
| 6 | Navigating or reloading immediately after typing a reflection lost the last edit. | Persist the reflection on input; debounce only the status message. | Reflection survives immediate navigation and reload. |
| 7 | Imported/saved flashcard HTML could execute scripts or unsafe links. | Sanitize both faces with a small inline-formatting allowlist and strip executable markup and attributes. | Browser regression with image/SVG event handlers and a JavaScript link, while preserving safe emphasis. |
| 8 | Flashcards hid their question/answer behind a generic accessible name, and grading controls stayed visible after flipping back. | Expose the visible face to assistive technology; show grades only when the answer is visible. | Accessible-name and flip-back browser regression; existing keyboard deck check. |
| 9 | A late account verification could restore a user after sign-out. | Guard verification with an auth epoch and handle the latest startup auth event. | Delayed verification and startup sign-out unit regressions. Saved-session recovery is also tested so the guard does not discard a legitimate returning session. |
| 10 | Guest edits made during a slow or failed account load could be lost. | Keep the guest workspace active and capture its latest state before switching to the verified account. | Delayed offline sign-in unit regression. |
| 11 | A late owner-report response could render private analytics after sign-out. | Guard responses by route, request, account, and generation; bound the request time. | Late owner-report unit regression. |
| 12 | Guests with only review cards, checklist results, or daily work were not offered progress import. | Consider those forms of progress when offering import. | Guest review-card import-offer unit regression. |
| 13 | Importing guest progress kept a lower account quiz score over a better guest score. | Preserve the better best score when both results describe the same number of questions. | Bidirectional best-score merge unit regression. |
| 14 | A failed lesson had no recovery action. | Offer a clear retry button and retain the selected lesson route. | Failed-fetch then successful-retry browser regression. |
| 15 | An initial failed search-index load left lesson text permanently unsearchable. | Retain successful fetches and retry failed documents when search is reopened. | Full-text recovery browser regression. |
| 16 | Moving an ordering item to a boundary disabled the focused button and lost keyboard focus. | Move focus to the enabled control on that same item. | Keyboard boundary-move browser regression. |
| 17 | Platform-parsed collector request bodies bypassed the 64 KiB limit. | Apply the byte limit to objects, strings, buffers, and streamed bodies. | Oversized multibyte object/string/buffer requests return 413; a normal empty batch returns 200. |
| 18 | Resetting a simulation let the old response timer advance the new session. | Invalidate the run on reset and stop callbacks for detached simulations. | Reset-during-response browser regression. |
| 19 | Failed clipboard operations still reported “Copied!”. | Confirm success; otherwise select the actual text and explain the manual copy action. | Browser regression rejects both clipboard APIs and checks the selection and feedback. |
| 20 | Search did not expose its keyboard-selected result, and empty results retained a stale active descendant. | Use a combobox/listbox relationship and update or clear the selected option. | Keyboard search and no-results accessibility regression. |
| 21 | Finishing background indexing reset the user's selected search result. | Retain the selected link for the same query when results are rebuilt. | Delayed-index keyboard selection browser regression. |
| 22 | A delayed file import could overwrite progress and replace the page after navigation or an account switch. | Require the original route and import control to remain current before applying the file. | Delayed-file navigation regression. |
| 23 | Pulling another device's progress erased the local certificate name; cached names were not restored on account loading. | Restore the cached local name and keep it with the notebook during background sync. | Cached-session and remote-progress browser regression. |
| 24 | False and obsolete progress entries inflated XP and exercise totals. | Count true results belonging to current lessons. | Seeded false/obsolete entries produce zero XP, completions, and solved exercises. |
| 25 | Malformed cloud progress could fail rendering after switching accounts and copy that account's notebook into the guest workspace. | Validate cloud/cache progress before applying it; never recapture an account workspace as guest data in the failure path. | Malformed-cloud privacy regression retains the account notebook and excludes it from guest state. |
| 26 | A malformed old guest cache could prevent account startup. | Validate guest restoration at startup and account transitions, with an empty safe fallback. | Bad-guest-cache regression loads the sign-in page without browser errors. |
| 27 | Older cards without a box value displayed NaN for XP and disappeared from box totals. | Default missing box values to box 1 consistently in stats, recommendations, ordering, and grading controls. | Legacy-card regression checks finite XP, the practice recommendation, and the box count. |
| 28 | Saved review dates could execute HTML in the empty-deck message. | Escape unformatted dates before inserting them into HTML, including certificate dates using the same formatter. | Malicious saved-date browser regression previously executed its handler; it now produces no injected image or execution. |

Wrong exercise fixture routes, a hidden copy control, and a whitespace-only assertion mismatch were corrected in the test harness and are not counted as product findings. No unverified finding was used to justify a code change.

## Evidence boundaries

Auth and cloud race regressions use intercepted network responses or an isolated lifecycle harness. This pass did not rerun privileged live database isolation checks or change database policies. A fresh live authenticated session restored successfully with the final code. The reported welcome lesson reached 100% reading progress and remained at scrollY 4241 with Progress synced; a later capture confirmed the same position. Earlier real provider setup is described in the account review. This is coverage of the current reviewed flows, not a guarantee that no further bugs exist.

Port 4173 is the approved local OAuth callback origin. Port 4174 is not currently allowlisted in Supabase; the user-facing preview was moved to 4173.
